# Livraisons de questions

Ce dossier est la **zone de dépôt** des banques de questions produites par l'équipe
pédagogique, conformément à [`../directive-donnees.md`](../directive-donnees.md) (§5.6).

Règles :

- un fichier CSV par livraison, nommé `questions-{langue}-{AAAA.MM}.csv` ;
- le modèle de colonnes est [`../modele-questions.csv`](../modele-questions.csv) ;
- une livraison déposée ici n'est **pas** encore en base : elle doit être convertie en JSONL,
  validée, puis importée par un développeur ;
- ne jamais déposer de données personnelles ni de contenu dont les droits ne sont pas clarifiés.
